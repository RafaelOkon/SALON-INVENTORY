# Salon & Beauty Products Inventory Management System

## Project Title

Inventory Management System

## Assigned Inventory Type

Salon and Beauty Products Inventory

## Description

A full-stack inventory management system designed to help salons efficiently manage beauty products, categories, suppliers, stock transactions, and users.

The system provides authentication, product management, category management, supplier management, stock management, dashboard statistics, low-stock monitoring, and reporting features.

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Node.js
- Express.js
- MySQL
- Git & GitHub

## Core Features

- User registration and login
- Password hashing
- JWT authentication
- Protected API routes
- Product management (CRUD)
- Category management (CRUD)
- Supplier management (CRUD)
- Stock management
- Stock-in and stock-out transactions
- Product search and filtering
- Dashboard statistics
- Low-stock monitoring
- Out-of-stock monitoring
- Recent stock transaction history
- Stock overview chart
- Low-stock alerts
- Client-side and server-side validation
- Error handling
- Responsive user interface
